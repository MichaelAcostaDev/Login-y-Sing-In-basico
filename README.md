# Login & Sign In Básico 🔐

A simple **Login and Sign Up interface** built with HTML5 and Bootstrap 5.2.3.

This project was created as a practical exercise to build and structure basic authentication interfaces on the frontend, focusing on forms, responsive layouts, Bootstrap components, and navigation between login and registration pages.

> **Note:** This project is frontend-only. It does not include a backend, database, user authentication system, or credential validation.

## 📋 About the Project

The application consists of two main pages:

* **Login:** Allows users to enter their email and password through a simple login form.
* **SignIn:** Provides a registration form where users can enter their name, email, password, and password confirmation.

Both pages share the same visual style and allow the user to navigate between login and registration.

The interface uses a centered card layout with a gradient background and Bootstrap utility classes to create a clean and responsive design.

## 🔒 Authentication Disclaimer

Although the project visually represents a Login and Sign Up system, it **does not implement real authentication**.

The forms currently serve as a frontend demonstration and do not:

* Store users.
* Validate credentials against a database.
* Create accounts.
* Encrypt passwords.
* Maintain user sessions.
* Connect to an API or backend.

A production authentication system would require a backend, secure password handling, persistent storage, validation, session management, and additional security measures.
